# SurfsUP logo

An original Lake Michigan silhouette with a curling wave, generated with the built-in ImageGen tool. No reference images or previous logo assets were used.

- `surfsup-logo-source.png`: unmodified 1254 × 1254 transparent source.
- `../../app/static/surfsup-logo.png`: 112 × 240 transparent header export, with excess canvas padding cropped.
- `../../app/static/surfsup-favicon.png`: 128 × 128 transparent browser icon.

Exports use macOS `sips` to crop canvas padding and resize, preserving alpha. The source is retained for future exports.

## Final generation prompt

Use case: logo-brand. Create one original standalone symbol for SurfsUP, a Lake Michigan surf conditions website. No lettering or words. An artistic, clean, compact emblem whose outer silhouette is recognizably Lake Michigan: long north-south lake, broad organic northern basin with a subtle Green Bay inlet on its northwest, narrowing toward a softly rounded southern end. Integrate ONE expressive curling surf-wave cutout into the lower interior of the lake shape, without destroying the lake outline. A tasteful hand-cut print / modern outdoor-brand aesthetic, bold simplified shapes with a little organic character, crisp edges. Muted seafoam mint #99dfcc and warm off-white #eef1e9 with a restrained deeper teal accent. Designed to sit beside a wordmark on a deep slate #101c23 website header and remain readable at 56px and as a favicon. Center one large mark with modest padding on a genuinely transparent background, square canvas. No badge frame, no glow, no circuits, no photography, no mockup, no flags, no three parallel wavy strokes. This is a wholly new design; do not reuse any previous images.
